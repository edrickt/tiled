Tiled 1.5.3 makes the title-bar double-click cover the whole top strip and
stops slow second clicks from expanding by accident. If double-clicking
Firefox's tab bar usually did nothing — or two careful single clicks
unexpectedly filled the screen — this is the fix.

## Install

1. Download `Tiled-1.5.3.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.5.3.zip.sha256`.

## What changed

- **The whole top strip expands.** Double-clicking anywhere in a window's
  top strip now runs the expand toggle: the background, tabs, toolbar, and
  title text alike. Tabbed windows answer a different accessibility role
  for the same spot across runs, so limiting the gesture to a few roles
  left most of the strip dead — in Firefox it only worked near the
  strip's top-left. The strip itself still decides: a double-click below
  it is content and stays with the app.
- **Only a crisp double-click expands.** The gesture used to follow the
  system's click count alone, so two deliberate single clicks inside the
  system's double-click interval filled the screen. The second click must
  now land within two tenths of a second of the first; a slower second
  click stays with the app.

Everything else is unchanged: quarters and sixths, the eleven shared slot
keys, live edge resizing, undo, expand, evict, drag-out, per-display and
per-Space canvases, and remappable shortcuts all work as in 1.5.2.
