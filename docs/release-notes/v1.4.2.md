Tiled 1.4.2 puts a title-bar double-click back on Tiled's expand toggle,
wherever on the title bar it lands — the title bar's background, an empty
unified toolbar, and the window's centered title text.

## Install

1. Download `Tiled-1.4.2.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.4.2.zip.sha256`.

## What changed

- **The whole title bar expands.** A double-click on the window's title
  text — the usual target, centered on the title bar — or on an empty
  unified toolbar used to fall through to the app's own Zoom/Minimize action
  (macOS's "double-click a window's title bar" setting) instead of running
  Tiled's `⌥⇧⏎` expand toggle. The gesture now recognizes those regions, plus
  the title-bar background it already covered, and consumes the click.
- **Content double-clicks stay with the app.** The toggle only answers a
  double-click that lands in the window's 28pt title-bar strip, measured from
  the window's own top edge, so a double-click in a text editor still selects
  a word and a toolbar control still does its own job.
- **Reliability on tiled windows.** The title-bar geometry the gesture
  requires was measured in the wrong coordinate space, so a window that did
  not touch the top of the screen — every tiled window — handed its
  title-bar double-click to macOS instead of expanding. The strip now hangs
  from the window's own top edge.

Nothing else in the window manager changed in this release.
