Tiled 1.3.3 keeps fullscreen presentations tiled: entering native
fullscreen no longer untiles the window or corrupts the canvas's tile
sizes, and exiting lands back on the tile with the splitters untouched.

## Install

1. Download `Tiled-1.3.3.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.3.3.zip.sha256`.

## What changed

- **Fullscreen frames are never gestures.** A frame covering the
  display's full frame is swallowed on arrival — baseline only, no
  splitter commit, no drag tracking, no decision — so a presentation
  neither moves a splitter nor borrows the clicked button's press
  evidence for a drag-out. A drag landing fullscreen drops silently,
  and a drag-end whose window is a fullscreen presentation is dropped
  instead of reasserting or untiling the window.
- **Resize commits require the hand.** A resize-shaped tick with the
  button up is a programmatic change (a fullscreen animation, an app
  self-resize): it updates the diff baseline but never moves a splitter
  or arms a reassert. Edge-splitter commits now match the documented
  rule that only the button-down drag moves them.
