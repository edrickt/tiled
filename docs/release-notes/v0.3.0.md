Tiled 0.3.0 is the shared-slot-keys release: one set of eleven slot keys
now means the matching position in whichever layout is showing, a new
⌥⇧\ switches that layout explicitly, and the menu bar answers every
action once.

## Install

1. Download `Tiled-0.3.0.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-0.3.0.zip.sha256`.

## What's new since 0.2.2

- **One set of slot keys for both layouts.** Eleven shared ⌥⇧ keys
  (U I O M , . J K L H ;) mean the matching position in whichever layout the
  canvas is showing, so there is no separate quarter set to learn or
  rebind. A key with no slot in the active layout is inert and says where it
  belongs. Tiled registers 17 hotkeys: 11 slot keys and 6 app actions, all
  remappable.
- **Switch Layout (⌥⇧\).** A new app action switches the layout of the
  display under the pointer — with or without a window there — untiles every
  tiled window on it, and restores each to its pre-tile frame. One undo
  brings back the windows and the previous layout. The layout is a stored
  canvas choice, so an empty canvas keeps it, and the menu's Switch Layout
  row still follows focus.
- **The menu bar answers once.** Every action speaks through one receipt and
  one notice: Evict, Untile All, a single window's untile, and Undo announce
  success only when the controller acted, a refused restore says so instead
  of claiming success, the re-house notice names the slot a window finally
  holds, and the manage menu follows the focused canvas (no "Untile 0
  Windows", no Reset Splitters row when nothing is tiled there).
- **Slot parking, refined.** The Shortcuts tab groups App Actions (6) and
  Slot Keys (11), parks the eleven slot combos with one Disable all, and
  restores a parked snapshot atomically — keeping a clash-skipped entry for
  a retry and leaving registration failures visible beside a partial
  restore.

### Breaking: the quarter hotkeys retire

Quarter-specific overrides and parked combos are gone. The shared keys
persist under the sixths slot names, so sixths overrides, parks, and reset
backups survive untouched; the six old quarter storage names (`topLeft`,
`topRight`, `bottomLeft`, `bottomRight`, `leftHalf`, `rightHalf`) are
deleted once at launch. Quarter placements now use the same ⌥⇧ modifiers as
sixths rather than ⌥⇧⌘, and a slot press no longer switches layouts.

## What's fixed since 0.2.2

- **Tiles land where the slot is.** The live AX adapter writes the AppKit
  top-left corner instead of the bottom-left origin, so a bottom-row tile no
  longer lands a full window-height below its slot with only the title bar
  left on screen.
- **Drags are read by what a hand can do.** A title-bar drag whose first tick
  carries a size change the app absorbed moves the window instead of yanking
  a splitter; a programmatic window jump — even a multi-tick one — snaps back
  instead of untiling, while a real far tick from a hand press still drops
  where released; and a short drag after a write that was skipped because the
  window already held its frame snaps back instead of leaving it offset.
- **Expanding supersedes a pending edge drag,** so the next mouse-up can no
  longer rewrite the splitters or move neighbours from the expanded window's
  screen-sized frame.
- **The reset-splitters hotkey restores its parked backup** instead of
  overwriting it with the already-reset grid, and menu and hotkey speak one
  receipt; a refused reassert is no longer announced as a successful reset.
- **A retiled or expanded window stays where you put it:** a hidden Space's
  swipe-back restore no longer writes the old frame and pulls the window off
  its new slot, and a refused undo re-place or expand keeps the source
  canvas's deferred pre-tile restore alive.
- **Refusals are reported as refusals.** A swap rolled back after the
  requester's write was refused names the failed home write too, every lost
  write is named beside its neighbours, and a refused write clears its armed
  convergence expectation and reseeds the drag baseline so a late check
  cannot evict a window that never moved there.
- **The Welcome guide tells the truth:** its Accessibility warning and grant
  button appear whenever the install is untrusted (including the first open
  after Settings was built) and hide when permission arrives, and it stops
  teaching a combo that lost global registration, naming the menu row
  instead.
- **Corrupt stored shortcut data with negative modifiers** is ignored like
  any other unreadable entry instead of trapping when Settings opens or a
  parked section is restored.
- Still fixed from 0.2.2: detaching a tab from a tiled Firefox window no
  longer untiles the original window.

### Under the hood

- The menu bar reads one snapshot from its canvas key through one presenter,
  and the status glyph draws in its own renderer.
- Each live window handle has one binding in a register, and one canvas
  directory owns display plus Space identity — including the last display
  the cursor was seen on, which the glyph and Switch Layout resolve through.
- Frame writes go through one policy that now owns the diff baseline;
  placement, swap, and reflow rollback run as one write transaction with one
  composed failure list; drag ticks are classified by their edge shape.
- The controller test harness injects deterministic displays and the prune
  scheduler, and the bulk, gateway, undo-integrity, reflow/swap/expand,
  Space-independence, and per-display suites run through it.
- Hotkey registration, teardown, and routing are testable, with one
  process-wide Carbon router that clears its handler with the service.
- The mutation gate can resume (`--resume`), re-scores the whole table when a
  test or `Package.swift` changes, and merges verdicts into
  `build/mutation-results.json`; a quiet test runner plus one count gate keep
  the published count honest.
