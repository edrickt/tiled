Tiled 1.2.0 changes the starting point and the feel of getting
windows out of tiles. Fresh canvases start in Quarters, so the first
slot key on a new display or Space tiles a quarter, and dragging a
window out of its tile takes a shorter pull than before.

## Install

1. Download `Tiled-1.2.0.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.2.0.zip.sha256`.

## What changed

- **Quarters is the default layout.** A new display or Space starts with
  the 2×2 grid, and the no-arg layout switch from a fresh canvas goes to
  Sixths. One shared definition owns the default, so key resolution, the
  switch target, and undo reconciliation can never disagree about it.
- **Easier drag-out.** Untling by dragging now takes ~25pt of title-bar
  travel instead of ~50pt; a shorter drag still snaps back into the tile.
