Tiled 1.3.0 makes floating windows predictable: every window that
leaves tiling — and every newly opened window — lands at quarter size,
whatever layout the canvas shows.

## Install

1. Download `Tiled-1.3.0.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.3.0.zip.sha256`.

## What changed

- **Quarter size everywhere.** New windows open at quarter size on any
  canvas, and manual untile, evict, untile-all, layout switch, and drag-out
  all leave the window at the quarter footprint (top edge kept, kept inside
  the visible frame). A Sixths canvas no longer floats sixth-size windows;
  one undo still restores the windows and the previous layout after a
  switch.
