Tiled 1.1.0 changes what happens when windows leave tiling — and when
they first appear. An untiled window no longer snaps back to whatever
shape its app gave it, and a brand-new window is no longer left at
whatever size it opened with. Both land floating at the canvas layout's
regular footprint: quarter size on a Quarters canvas, sixth size on a
Sixths canvas, hung from the window's top edge with the bottom edge
pulled up to the grid's size.

## Install

1. Download `Tiled-1.1.0.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.1.0.zip.sha256`.

## What changed

- **Untiled windows keep a tile-sized footprint.** Manual untile, eviction,
  untile-all, layout switch, and drag-out all leave the window floating at
  the layout's regular even-split footprint instead of restoring its old
  pre-tile frame. The window keeps its top edge and pulls its bottom edge
  up to the grid's size, repinned inside the visible frame, and undo
  chapters store the sized frame so a return trip agrees with itself.
- **The footprint ignores drag-edited splitters.** Live edge drags can
  reshape the grid, but a freed window always takes the regular
  quarter/sixth size — never the smallest sliver a drag left behind.
- **New windows open at the canvas footprint.** A window Tiled has never
  seen is sized to the cursor display's canvas layout the moment it
  appears, and stays floating: Tiled never auto-tiles. Only a landed
  write claims anything; a refused write leaves the window exactly where
  its app put it.
