Tiled 1.3.5 fixes fast drag-outs. Dragging a tiled window out of its tile
quickly past the untile distance no longer snaps it back: the window untiles
where you dropped it, exactly like a slow drag.

## Install

1. Download `Tiled-1.3.5.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.3.5.zip.sha256`.

## What changed

- **A fast drag out of a tile untiles where you drop it.** macOS can report a
  quick drag's final position a few milliseconds after you release the mouse
  button. Tiled used to read that late report as a programmatic window move
  and snapped the window back into its tile; it now recognises the release
  the report belongs to and keeps the drop. A drag that starts slowly and
  finishes fast is handled the same way, and short drags still snap back.
  Slow drags, edge resizes, and clicks are unchanged.
