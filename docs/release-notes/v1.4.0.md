Tiled 1.4.0 adds a second way to fill the screen, and keeps the screen to one
full-size window.

## Install

1. Download `Tiled-1.4.0.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.4.0.zip.sha256`.

## What changed

- **Double-click a window's title bar to expand it.** The gesture runs the
  same `⌥⇧⏎` toggle as the hotkey, for the window you double-clicked even
  when it isn't focused. Tiled consumes the double-click, so macOS's own
  title-bar double-click action (Zoom, Minimize, or whatever your System
  Settings names) never runs for a title bar it recognizes. Double-clicking
  a window's content is left alone, and Tiled's own Settings window keeps
  the system behavior.
- **One full-size window per display and Space.** Expanding a second window
  fills the screen with it and puts the window that was covering the layout
  back in its tile (or back to the frame it had before expanding). If that
  window's app refuses to return it, the new expansion is rolled back and
  Tiled says which window would not move, instead of leaving two full-size
  windows stacked. Different displays and Spaces each keep their own
  full-size window.
- **Off-Space expansions follow the same rule.** An expansion or collapse
  waiting for a hidden Space to return applies when you swipe back, and the
  newest request wins if you asked twice.
