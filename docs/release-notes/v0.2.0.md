Tiled 0.2.0 is the second release: every hotkey is now remappable, Reset
Splitters gets a global shortcut of its own, and eviction grew a smarter
step-aside rule.

## Install

1. Download `Tiled-0.2.0.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-0.2.0.zip.sha256`.

## What's new since 0.1.0

- **Every hotkey is remappable.** The Shortcuts tab gains a collapsible App
  Actions section covering Expand, Evict, Reset Splitters, Settings, and Undo,
  so all 22 combos can be rebound, disabled, parked, and restored with the same
  machinery the 17 slot combos already used. A customized combo renders
  everywhere it used to be hardcoded, including the menu and the Welcome guide.
- **Reset Splitters (⌥⇧R).** A new global hotkey for the menu's Reset
  Splitters: snap the focused canvas back to even splits with every window kept
  in its slot, then press it again to restore the previous positions.
- **Smarter eviction.** A single blocker whose slot contains the requested tile
  now steps aside into its leftover strip instead of being untiled — the left
  third asked for its top sixth slides down into the bottom-left sixth — and
  that holds for tiled requesters too. Undo restores the whole chapter.
- **Resize clamping stays on screen.** A neighbor pushed below its app's
  minimum size now stops at the screen edge instead of growing off it, so a
  window past its floor simply stops shrinking.

### Under the hood

- A canvas's placement, records, expansion, and splitters now live in one deep
  module per canvas (`TilingSpace`), and menus and tests read that single
  per-canvas surface instead of re-deriving state.
- Frame writes go through one `FrameWriter` policy module, so the no-op skip,
  off-Space deferral, echo marking, and late check live in one place.
- The mutation gate runs mutants in parallel copy-sandboxes (~3 minutes for the
  full table, down from ~15) and gains `--since <ref>` to score only the mutants
  a given change can affect.

## Quality

- 613 hermetic unit tests over the pure engine through `FakeWindowGateway`,
  plus a 50-mutant audit where every injected bug is caught, and the live
  end-to-end suites for the pre-release pass.
- No network, no telemetry, no persisted window state; see
  [`SECURITY.md`](https://github.com/edrickt/tiled/blob/master/SECURITY.md).
