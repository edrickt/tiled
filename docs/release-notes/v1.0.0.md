Tiled 1.0 is the first stable release. There are no code changes
since 0.3.2: the audited 0.3.x foundation is now the stable behavior
Tiled promises going forward.

## Install

1. Download `Tiled-1.0.0.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.0.0.zip.sha256`.

## What 1.0 means

- **Eleven shared ⌥⇧ slot keys** tile into quarters or sixths on the
  display under the pointer; **⌥⇧\** switches that display's layout,
  explicitly and undoably.
- **Live drag-resize** of shared edges with app-floor-aware reassert, and
  **one-step undo** of every displacement from the Tiled menu.
- **Truthful menus:** one notice, named apps on refusal, no promises the
  layout cannot keep.
- **No stranded windows:** a deleted Mission Control Space retires its
  canvas instead of deferring against it forever.
