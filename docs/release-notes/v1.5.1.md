Tiled 1.5.1 is a reliability fix for expanded windows. An expanded window
now keeps filling the screen when the screen's geometry changes; nothing
else about the app changed.

## Install

1. Download `Tiled-1.5.1.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.5.1.zip.sha256`.

## What changed

- **An expanded window follows a changed screen.** Changing a display's
  resolution, moving the Dock or menu bar, plugging a display back in, or
  waking from sleep re-asserts the canvas. That reassert used to leave the
  expanded window at the frame it had when you pressed the toggle, so it
  could overflow a smaller screen or stop covering a larger one while Tiled
  still called it expanded. The reassert now re-fills the expanded window to
  the new visible frame, and the swipe back after a Mission Control Space
  switch does the same; it still never moves the window into its slot. Only
  the toggle collapses it. If the app refuses the re-fill, the menu says so
  and the window keeps its frame.
- **Documentation corrections.** The user guide now names the persistent
  display UUID as the canvas identity key, and the code comments no longer
  describe a birth resize that 1.5.0 removed.

Everything else is unchanged: quarters and sixths, the eleven shared slot
keys, live edge resizing, undo, expand, evict, drag-out, the whole-title-bar
double-click gesture, per-display and per-Space canvases, and remappable
shortcuts all work as in 1.5.0.
