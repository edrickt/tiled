Tiled 1.5.2 fixes floating windows sinking behind the tiled layout. If
you keep floating apps open next to your tiles, closing any window no
longer buries the floating window you are working in.

## Install

1. Download `Tiled-1.5.2.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.5.2.zip.sha256`.

## What changed

- **Floating windows stay on top while you use them.** With tiles holding
  the layout and floating apps open beside them, closing a window used to
  lift every tiled window above everything else — so the floating window
  you were using could disappear behind the tiles. That raise now happens
  only when it should: when a tiled window is evicted, untiled, or dragged
  out and its restored frame stays on the canvas below the survivors.
  Closing a window, or a window going away on its own, leaves the
  z-order of your floating windows alone.

Everything else is unchanged: quarters and sixths, the eleven shared slot
keys, live edge resizing, undo, expand, evict, drag-out, the whole-title-bar
double-click gesture, per-display and per-Space canvases, and remappable
shortcuts all work as in 1.5.1.
