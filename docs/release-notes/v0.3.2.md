Tiled 0.3.2 is a hygiene release. There are no new features and no
behavior changes: the build is warning-free, the prose matches the
glossary, and the one open undo question from the last audit is now
pinned by a regression test.

## Install

1. Download `Tiled-0.3.2.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-0.3.2.zip.sha256`.

## What's fixed since 0.3.1

- **Warning-free build.** A leftover binding and two discarded results are
  fixed at the source; `swift build` reports nothing.
- **Prose matches the glossary.** A second sweep replaces "monitor" with
  "display" wherever it meant the display dimension.
- **Self-untile undo, pinned.** Undo after untiling the focused window
  restores the reflowed neighbor and leaves the untiled window where it
  was put — now covered by a regression test, so the behavior is a
  decision on record rather than an open question. Whether undo should
  instead re-tile there is parked as a product call.

## Quality

- 959 hermetic unit tests over the pure engine through the fake gateway.
- A 149-mutant audit where every injected bug is caught.
- The exhaustive undo replay (653 reachable boards, 11,931 chapters)
