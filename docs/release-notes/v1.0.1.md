Tiled 1.0.1 is a bug fix. Some apps could not be tiled at all: every
slot key did nothing, with no notice saying why. Spotify was the app
that surfaced it.

## Install

1. Download `Tiled-1.0.1.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.0.1.zip.sha256`.

## What changed

- **Apps that never report a focused window can be tiled again.** Spotify
  (a Chromium-based app) tells macOS it has no focused element, so the
  system-wide "which app has focus" question came back empty and Tiled
  found no window to tile: the shortcut was a silent no-op. Tiled now asks
  macOS's frontmost app instead when that answer is missing — and only
  then, so an answer macOS gave is never second-guessed. Verified against
  Spotify 1.3.3 on macOS 26.

## Known limit

Spotify refuses to shrink below 800×600 points. On a 1680×1019 display
that rules out quarters, sixths and thirds; halves and two-thirds fit.
Tiled currently keeps Spotify at its floor and says nothing about it. The
open question — report the floor, or refuse the placement — is tracked in
the issue tracker and not settled here.
