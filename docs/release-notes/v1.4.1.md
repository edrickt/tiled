Tiled 1.4.1 makes a new window land at the quarter footprint as its first
effect, instead of opening at its app's own size and then resizing.

## Install

1. Download `Tiled-1.4.1.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.4.1.zip.sha256`.

## What changed

- **New windows land at quarter size immediately.** Tiled now sizes a new
  window from the window-creation notification itself: it reads the new
  window's frame once, writes the quarter footprint as the first thing it
  does, and only then records and observes the window. Everything else the
  birth path used to read first (the app's window list, a liveness probe, a
  second frame read) now follows the write or is skipped, so the app's own
  window-opening animation retargets to the quarter footprint about a
  display refresh earlier instead of the window sitting at the app's size
  for several animation steps and then snapping down. Measured live: the
  quarter footprint appears ~16 ms after the window opens instead of
  ~30 ms, and the size write lands ~5 ms after the window opens instead of
  ~14 ms. A window whose app has already put an opening frame on screen can
  still show one frame at its own size; that first frame is macOS's own
  window appearance, which Tiled cannot preempt.
- **Tab-switch churn still adopts.** Tiled reads an app's window list only
  when the newborn could be a churned identity (Terminal replaces its
  window element on every tab switch), so a tab switch keeps adopting the
  existing window instead of resizing a tiled one.
- **Untiles are unchanged.** Evict and untile already landed the quarter
  footprint in one direct write, with no intermediate frame.
