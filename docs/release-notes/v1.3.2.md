Tiled 1.3.2 fixes the unpredictable quarter sizing: new windows size on
their own display, tab-switch churn adoption is deterministic and
jitter-tolerant, and every canvas action re-resolves stale display
geometry first.

## Install

1. Download `Tiled-1.3.2.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.3.2.zip.sha256`.

## What changed

- **Births size on the window's display.** Births were sized from the
  cursor display's canvas, so a window opening on another display was
  pinned into the wrong screen — and a hidden-Space birth could write
  blind through the cursor's visible canvas, bypassing the off-Space
  deferral. The birth and drop canvases now resolve from the window's
  frame, falling back to the cursor only when the frame resolves to no
  display.
- **Tab-switch adoption is deterministic.** When several same-app
  windows match a newborn frame, the closest frame wins and exact ties
  break to the smallest handle id — never Dictionary order. Matches
  within two points, so rounding plus a display-change or Dock nudge
  still reads as the same window.
- **Actions re-resolve stale geometry.** Every canvas action refreshes
  its stored frame from the live display set first, so a Dock toggle
  that fires no display-change notification no longer skews birth and
  untile sizes. Detached displays keep their frame as before.
