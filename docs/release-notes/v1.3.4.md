Tiled 1.3.4 is a correctness release following a full audit of the app's
major features: display identity, births, live drag/resize, undo and
receipts, shortcuts, the menu bar, and settings/permissions.

## Install

1. Download `Tiled-1.3.4.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.
   (Each reinstall needs one re-grant: the ad-hoc signature changes
   every build.)

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-1.3.4.zip.sha256`.

## What changed

- **A display keeps its layout across a renumber.** Canvas identity is the
  display's persistent CoreGraphics UUID, not its transient display number,
  so returning from sleep/wake, a dock change, or a replug no longer strands
  the display's windows and splitters. A reused number never inherits
  another display's canvas.
- **The shortcut recorder can record what is already bound.** Global
  registrations suspend while a recorder is armed, so choosing a combo that
  is currently in use shows the conflict instead of firing that action
  behind Settings. A failed Carbon event tap is surfaced instead of leaving
  every hotkey silently dead.
- **Drag and drop fixes.** A pending edge reassert can no longer erase
  another window's live drag-out, and a drag-out dropped on another display
  stays where it was dropped.
- **Menu and undo fixes.** Background-canvas refusals appear with their
  display, a layout-only undo no longer claims windows returned, mixed-layout
  display headers no longer assert one layout, and "Tile Focused Window
  Here" answers honestly when its window is on another canvas.
- **Settings and permissions fixes.** Granting Accessibility refreshes the
  open Settings content, the Guide raises Settings, a hidden-icon grant
  restores a visible surface, and the permission poll stops when the
  explainer closes.
- **Resize and expand fixes.** Expanded windows keep the live and reassert
  splitter rules in agreement, a refused collapse keeps its saved frame, and
  an unreadable-frame expand reports that it did not perform.
- **Smaller fixes.** Tiled no longer sizes its own Settings/Welcome windows
  at birth; focus-only Accessibility bindings are released; birth sizing
  falls back to the cursor display for a frame no display owns; and the
  build is warning-free again.
