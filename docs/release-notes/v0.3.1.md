Tiled 0.3.1 is a quality release. The October code-quality audit fixed
nine release-blocking defects and a batch of smaller ones across tiling,
undo, live resizing, menus, hotkeys, and Mission Control Space identity.
There are no new features and no breaking changes.

## Install

1. Download `Tiled-0.3.1.zip` below and move `Tiled.app` to `/Applications`.
2. On first launch, right-click the app and choose **Open** (the bundle is
   ad-hoc signed; there is no Developer ID yet).
3. Grant Accessibility permission when Tiled asks, then relaunch it.

Universal bundle (Apple Silicon and Intel), macOS 13 or later. The attached
`.sha256` verifies the download:
`shasum -a 256 -c Tiled-0.3.1.zip.sha256`.

## What's fixed since 0.3.0

- **A drag's mouse-up always decides.** A sub-pixel final tick no longer
  cancels a title-bar drag, and a live drag is decided before the edge
  reassert that used to erase it — so a drag-out can no longer leave the
  window dropped over its still-occupied slot, and the splitters no longer
  reconcile from the dropped frame.
- **A refused frame write stays refused.** If an app refuses the position
  write, Tiled no longer follows it with the size write: the window is left
  exactly where it was instead of being reshaped in place while the layout
  rolls back.
- **A deleted Mission Control Space no longer strands windows.** When the
  Space a canvas lived on is deleted, the canvas is retired and the window
  tiles again on the Space macOS moved it to, instead of deferring forever
  against a canvas that can never become visible.
- **The menu tells one story.** A background action no longer repeats the
  focused canvas's error row; a window whose display holds both a named and
  a withheld canvas stays under its own display's header with that header's
  count; and undo says "Undo from the Tiled menu" instead of a hardcoded
  combo, so a remapped Undo still points somewhere real.
- **No false success after a failed restore.** A re-house whose fallback
  restore is refused now names the app in the menu rather than reporting
  that the window went back.
- **Shortcuts fail safe.** A corrupted stored value outside the usable
  range degrades to the factory default instead of trapping when Settings
  opens; clearing an app action no longer parks its combo where nothing
  could restore it; and clearing a failing combo no longer leaves its old
  warning on screen.
- **Undo restores the arrangement it re-tiles,** raises it above the
  restored windows, and never offers "Restore 0 Displaced Windows".
- **Reset Splitters keeps its one-press contract:** while a backup is
  parked, the same press restores it instead of overwriting the only way
  back.
- **Smaller fixes:** a closed window's parked restore is dropped instead of
  naming a ghost on the swipe back; the Welcome tab announces a permission
  change instead of changing layout silently; bindings opened only for
  focus reads are released when their app quits.

## Quality

- 958 hermetic unit tests over the pure engine through the fake gateway.
- A 149-mutant audit where every injected bug is caught.
- The exhaustive undo replay (653 reachable boards, 11,931 chapters) is now
  a standing gate, not a one-off.

The README's glyph and Switch Layout paragraphs now match the shipped
rule: both follow the display under the pointer, while the tiled-window
rows and the menu's Switch Layout row follow focus.
