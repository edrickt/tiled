## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/<arc>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: the domain glossary is `CONTEXT.md`; ADRs, once any exist, live in `docs/adr/`. See `docs/agents/domain.md`.
