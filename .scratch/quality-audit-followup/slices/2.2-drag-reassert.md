## Per-area verdicts

### Edge / Splitter fractions — sound, pinned

`processResize` (`DragTracker.swift:621:669`) maps each moved edge through
`GridLayout.boundary(edge:slot:)` and divides the dragged window's own edge
position against the canvas's stored visible frame
(`DragTracker.swift:625`), never against the window's own geometry. The
occupant-aware two-thirds centering rule is shared with the reassert core
(`DragTracker.swift:650:659`, `TilingSpace.swift:1582:1585`), and a corner
drag moves each edge independently in one pass (`DragTracker.swift:632:660`).
Pinned by `DragTrackerTests.swift:140:225` (canvas-frame division,
hidden-Splitter centering from either side, corner two-edge move).

### Minimum-size clamp vs achieved frame — sound, pinned

The reassert core trusts the achieved frame over the stored Splitter
position: `reconciledGrid` moves each movable edge of the dragged slot back
to the achieved edge before any occupant rect is derived
(`TilingSpace.swift:1572:1588`), and `reassertPlan` derives every
non-expanded occupant rect from the reconciled splitters
(`TilingSpace.swift:1554:1561`), so neighbours abut the window itself.
The corrective readback extends the same authority to every written
occupant whose app rounds or insets a written frame
(`TilingSpace.swift:1661:1690`, bounded at `1633:1639`). The write policy
repins a clamped frame inside the canvas visible frame
(`FrameWriter.swift:122:174`). Pinned end to end by
`ReassertPlanTests.swift:42:127,239:287`, `MinimumSizeTests.swift:69:148`.

### Fixed-edge snapback — sound, pinned

Any moved edge marks the canvas's reassert pending even when it maps to no
Splitter (`DragTracker.swift:661:668`), so a drag confined to a fixed
visible-frame edge still owes the canvas a reassert on release, and the
release reasserts every occupant rect under the untouched splitters, pulling
the edge home (`TilingSpace.swift:1554:1561` with a `.grid` source).
Pinned by `DragTrackerTests.swift:309:332`.

### Pending reassert vs Expand (F12) — confirmed pinned, no regression

Landed Expand and collapse each discard the window's pending edge reassert
(`TilingSpace.swift:1386`, `TilingSpace.swift:1427` via
`DragTracker.swift:284:286`), the pure plan omits expanded occupants from
the rects it writes (`TilingSpace.swift:1557`), and the Splitter reconcile
refuses an expanded dragged window (`TilingSpace.swift:1572:1576`), so a
stale edge drag surviving an Expand can never reconcile the Splitters from
the expanded window's full-visible-frame frame. The row-state half holds too:
`expandToggleState` names the held slot for an expanded slot occupant and
the saved frame otherwise (`TilingSpace.swift:236:240`). Pinned by
`DragTrackerTests.swift:289:307` and `ReassertPlanTests.swift:186:216`.
**F12 re-verification: confirmed pinned.**

### Drag-out gating + skipped-write seeding (ticket 12, ex-F14/F18) — confirmed pinned, no regression

A far tick decides a Drag-out at release only with fresh per-window hand
evidence: the press point must fall inside the window's start frame and stay
fresh via button-held movement (`DragTracker.swift:139:144,556:573`,
`584:607`, `689:701`); the release clears the evidence
(`DragTracker.swift:712:730`). A programmatic jump — single- or multi-tick —
snaps back even when an unrelated press and release land inside the
debounce. A write skipped as already-correct seeds the drag baseline without
arming an echo entry (`FrameWriter.swift:102:109`), a refused write reseeds
from the frame the gateway still reports (`FrameWriter.swift:111:120`), and
the reassert seeds every occupant it is about to write, including deferred
ones (`TilingSpace.swift:1645:1649`, called at `1613` and `1627`). Pinned by
`DragTrackerTests.swift:586:712` (one-tick hand drag untiles; unrelated
click, outside press, stale press, and evidence-clearing all snap back;
held-button movement renews the stamp) and
`ReassertPlanTests.swift:340:384` (skipped-write and deferred seeding).
**Ticket-12 re-verification: confirmed pinned.**

### Splitter-backup pin (ticket 18, ex-T6) — confirmed pinned, no regression

Reset parks the pre-reset fractions and restores them through a reassert;
restore consumes the backup (`TilingSpace.swift:1487:1506`,
`hasSplitterBackup` at `1514`). The drag path never reads or writes the
parked backup — `processResize` only moves live Splitter fractions — so a
drag alone cannot arm a restore and a drag after a reset cannot clear one.
Pinned through the real controller plus tracker path by
`SplitterBackupDragTests.swift:49:91` (drag arms nothing; parked fractions
survive a drag; second reset replaces the snapshot).
**Ticket-18 re-verification: confirmed pinned.**

## New findings

### F21 (LOW): absorption past the translation margin still misroutes the first tick

**Evidence.** `DragTracker.swift:499:504` routes any tick whose size change
exceeds `translationMargin` (`DragTracker.swift:190`) straight to the
Splitter path, and the comment at `DragTracker.swift:496:498` records the
residual: an app absorbing more than the margin still misroutes its first
tick (the observed 82pt title-drag widening the slot it was leaving).

**Reachable sequence.** A slot occupant whose app silently rounds a written
frame by more than 8pt receives its first hand title-drag tick; the origin
travels with the drag while the size delta trips the margin, so the tick
reads as an edge grab and yanks the shared Splitter by the full origin
delta. The following release issues a snapback (a `.grid` reassert), which
rewrites the window home but leaves the yanked Splitter in place.

**Test gap.** `DragTrackerTests.swift:532:571` pins the small-absorption
shape (origin-dominant tick reads as a move) and the genuinely
size-dominant shape, but no test pins behavior past the margin: the residual
is documented only in the comment.

**Direction.** Consult the hand-evidence signal (or the echo trail) before
routing a size-dominant first tick to the Splitters, or bound the first-tick
Splitter travel; pin the chosen bound with a beyond-margin absorption test.

### F22 (LOW): one pending reassert per canvas — a second edge movement supersedes the first window's achieved-frame reconcile

**Evidence.** `pendingReasserts` keeps a single window per canvas
(`DragTracker.swift:151`), and every edge movement overwrites it
(`DragTracker.swift:661:668`); the release drains whatever entry remains
(`DragTracker.swift:712:730`).

**Reachable sequence.** Window A edge-drags on a canvas, releases (resize
for A emitted), then a trailing AX report re-arms A; before the next release
window B on the same canvas moves an edge, overwriting the entry with B. The
next release reasserts only B. B's reassert still rewrites A into its
reconciled slot, but A's own achieved-frame clamp reconcile never runs, so a
clamp A suffered stays unreconciled until a later reassert names A.

**Test gap.** `DragTrackerTests.swift:416:444` pins the single-window
trailing-tick shape; no test drives two windows' pending entries on one
canvas.

**Direction.** Keep the pending set per window (or per canvas holding every
pending window) and emit one resize decision per pending window; pin with a
two-window trailing-tick test asserting both achieved frames reconcile.

### F23 (LOW): an unreadable achieved frame at release silently drops the resize

**Evidence.** The coordinator's drag-end route returns without any reassert
when the achieved-frame read fails (`TilingController.swift:1156:1168`,
the `guard ... else { return }` at `1159`).

**Reachable sequence.** A release decision fires while the AX frame read is
in its unreadable transient (the lid-close shape the convergence path
already treats as can't-judge at `DragTracker.swift:322:326`): the stored
Splitter fractions keep the live-stored positions but no reassert runs,
so neighbours are not rewritten under them until some later reassert.

**Test gap.** No slice test drives the release route with an unreadable
achieved frame; the unreadable-frame leniency is pinned only for the
convergence verdict (`DragTrackerTests.swift:759:797`).

**Direction.** On an unreadable achieved frame, fall back to a `.grid`
reassert of the owning canvas so occupants still rewrite under the stored
Splitters; pin with a release-during-unreadable-frame test.
