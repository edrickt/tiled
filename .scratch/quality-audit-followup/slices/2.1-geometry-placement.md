## Per-area verdicts

### Plan / Swap / step-aside core — solid

- The plan matrix (`Sources/tiled/Layout.swift:535-560`) keeps every
  documented rule: same-slot noop (`:536`), layout switch when any
  occupant uses the other layout (`:537-539`), single-blocker Swap only
  when the requester holds a slot disjoint from the target
  (`:553-554`), with step-aside checked first (`:555`) so a blocker
  whose leftover is exactly one whole slot keeps its own strip
  instead of swapping.
- `stepAsideHome` (`Sources/tiled/Layout.swift:589-601`) and the
  free-cell-set rule in `rehousingHome` (`:623-639`) are both
  exact-or-nil and share the one step-aside helper, so the plan and the
  branch outcome cannot disagree about whether a home exists. This
  matches the Re-house definition in `CONTEXT.md`.
- The cross-check suite replays every occupancy × target against the
  plan with one layout and no double-booked cells
  (`Tests/tiledTests/MatrixCrossCheckTests.swift:14-18,95`); pure-state
  Swap/step-aside pins live in
  (`Tests/tiledTests/TilingStateTests.swift:75-138`) and the branch
  pins in (`Tests/tiledTests/SwapTests.swift:54-96`,
  `Tests/tiledTests/TilingSpaceTests.swift:300-330`).
- The degenerate Swap fallback (requester with no slot, or a vanished
  window) degrades to the ordinary eviction path with expanded-evictee
  closure intact (`Sources/tiled/TilingSpace.swift:587-602`), pinned by
  (`Tests/tiledTests/TilingSpaceTests.swift:355-369`).

### Re-house election and notice — solid

- Election covers a lone unexpanded evictee only, through the shared
  helper (`Sources/tiled/TilingSpace.swift:682-688`); the re-housed

### Reflow exact-or-nil, rightmost tie, exclusions — solid

- The pure rule (`Sources/tiled/Layout.swift:670-716`) merges freed
  cells with exactly one survivor into exactly one whole slot, prefers
  the rightmost grown slot then the larger slot (`:695-708`), and
  leaves holes that merge into nothing empty (`:709`). Cells that stay
  occupied are never treated as free, including the requester's fresh slot (`:677`).
- The canvas applier adds the expanded-window exclusion beside the
  caller-supplied skip set (`Sources/tiled/TilingSpace.swift:1121-1124`),
  writes through the one shared write policy, and restores every
  survivor's prior slot when a grow write is refused (`:1143-1155`), so
  state and display never disagree about the freed cells. The execution
  tail withholds Reflow unless the branch outcome is clean
  (`:344-355`), and folds survivor entries into the event's
  displacement chapter (`:394-403`).
- Pins: (`Tests/tiledTests/ReflowTests.swift:398-461`)
  (refused grow write restores the survivor, no chapter),
  (`:620-636`) (re-housed window returns to the slot it was evicted
  from), (`:638-654`) (expanded survivor never grows).

## New findings

### F21 (LOW): A Swap home-write after a refused requester write goes unread

**Evidence.** `Sources/tiled/TilingSpace.swift:629-639`: when the
requester write is refused, both occupancies are restored in state and
the displaced window is written home (`:635`), but that write's
outcome is discarded while the requester's refusal becomes the
branch's whole story.

**Reachable sequence.** Window A seated Top Left, B seated Top Right.
A asks for Top Right; the plan is a Swap. B's write into Top Left
lands (B visibly sits there); A's write into Top Right is refused. The
code restores both occupancies and writes B toward Top Right. When
that home-write is refused too, B visibly remains in Top Left while
state records Top Right — the disagreement F1 removed, through the
back door. A later request can then plan into Top Left over the
visible B.

**Test gap.** `testSwapRefusalByRequesterRollsDisplacedBack`
(`Tests/tiledTests/TilingSpaceTests.swift:311-330`) pins the
successful home-write only; no test refuses the second write.

**Direction.** Read the home-write through the shared write policy;
on refusal, surface the shared restore-failure message on the canvas
rather than keeping a silent disagreement (the displaced-first-write
refusal path at `:616-624` shows the shape: state-only restore plus a
named refusal).

### F22 (LOW): A Reflow recovery rewrite after a refused grow write goes unread

**Evidence.** `Sources/tiled/TilingSpace.swift:1143-1155`: when a grow
write is refused, survivor occupancies roll to their prior slots and
the old rects are re-written (`:1153`), discarding that pass's
outcome.

**Reachable sequence.** A survivor grows into freed cells on the display;
its grow write is refused, so state returns it to its prior slot and
re-writes the old rect. When that recovery write is refused as well,
the survivor visibly holds the grown slot while state records the
prior one, and Reflow reports no entries — a silent disagreement with
no chapter.

**Test gap.** `testRefusedReflowWriteRollsTheSurvivorBack`
(`Tests/tiledTests/ReflowTests.swift:398-411`) pins the successful
recovery only; no test refuses the old-rect rewrite.

**Direction.** Observe the recovery pass; on refusal, surface the
shared refusal message on the canvas (the `writeRects` helper at
`:1177-1196` already owns that message) so the disagreement is
announced instead of silent.
